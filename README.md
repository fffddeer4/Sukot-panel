## 🚀 درباره پروژه

**SUKOT PANEL** یک پروژه پنل مدیریتی با قابلیت اجرا روی زیرساخت Cloudflare است.

این پروژه با هدف ارائه تجربه‌ای ساده، مدرن و کاربردی توسعه داده شده است.

### ✨ مشخصات پروژه

| ویژگی | توضیحات |
|---|---|
| نام پروژه | SUKOT PANEL |
| نسخه | 2.5.0 |
| پلتفرم | Cloudflare Workers |
| پایگاه ذخیره‌سازی | Cloudflare KV |
| هوش مصنوعی پیشنهادی | Z.ai |
| وضعیت | توسعه پروژه |

---

## ⚡ آموزش راه‌اندازی پنل با Z.ai

برای راه‌اندازی پنل می‌توانی از هوش مصنوعی Z.ai کمک بگیری.

### مرحله اول: ساخت توکن Cloudflare

از طریق دکمه زیر وارد بخش ساخت توکن شو:

<a href="https://dash.cloudflare.com/profile/api-tokens">
<img src="https://img.shields.io/badge/🔑_CREATE_TOKEN-ساخت_توکن_CLOUDFLARE-F38020?style=for-the-badge" />
</a>

توکن را با دسترسی‌های موردنیاز پروژه ایجاد کن.

مجوزهای احتمالی:
- Workers Scripts: Edit
- Workers KV Storage: Edit
- Workers Routes: Edit (در صورت نیاز)

سلام!

می‌خواهم پروژه SUKOT PANEL را برای من راه‌اندازی کنی.

لطفاً مراحل زیر را انجام بده:

cf-config-panel-kv

6. پنل را Deploy کن.
